# EU icons for labelling AI-generated content

Official icons published by the European Commission:
https://digital-strategy.ec.europa.eu/en/policies/eu-icons-labelling-ai-generated-content

| File | Icon | Meaning |
|---|---|---|
| `ai-*.svg` | AI | basic icon: AI was involved |
| `ai-generated-*.svg` | AI GENERATED | content fully generated by AI |
| `ai-modified-*.svg` | AI MODIFIED | human-made content partially modified by AI |

Colour variants: `-black`, `-white`, and `-50` = 50 % transparency.

According to the Commission the icons are free to use and no attribution is
required. Using them does not signal adherence to the Code of Practice on
marking and labelling AI-generated content. The files are unmodified, only
renamed.
